# Яндекс.Музыка → Discord

Обычное приложение для Windows: Без командной строки и без лишних окон.

[Скачать](https://github.com/pavelinbs-afk/yamusicrpc/releases/tag/v2.2.3)

Типы установщиков после **[локальной сборки:](https://github.com/pavelinbs-afk/yamusicrpc/releases/tag/v2.2.3)**

- **`.exe`** (NSIS) — обычный мастер установки, ярлык в меню «Пуск».
- **`.msi`** — по желанию, тот же продукт в формате Windows Installer (удобно для корпоративных сценариев).
- **`portable.exe`** — один файл, без установки в систему.

Внутри уже упакованы программа, движок Electron и нужные библиотеки. **Пользователю Node.js ставить не нужно.**

## Что сделать

1. Установи программу из собранного `.exe`, `.msi` или portable (файлы появляются в папке `release/` после сборки).
2. Запусти установщик и пройди шаги (для portable — просто запусти файл).
3. Открой программу из меню **«Пуск»** или с ярлыка на рабочем столе.
4. Запусти **десктопное приложение Яндекс.Музыки** (не сайт в браузере), войди в аккаунт и включи воспроизведение.
5. Держи открытым **Discord** — в профиле появится статус «слушает …».
6. (Рекомендуется) В **Настройки → Статус** нажми **«Установить мост»** — в клиент вшивается тонкий скрипт для точных позиции, длительности, обложки и ссылки на трек. Перед этим закрой Яндекс.Музыку. Без моста статус всё равно работает через системный медиа‑транспорт (менее точно).

В окне программы сверху полоска **RPC**, рядом отображается **версия** (например `v1.5.2`), ниже — строка с текущим треком; кнопка **«Настройки»** открывает разделы в том же окне.

## Обновление со старой сборки

Если при запуске была ошибка **`spawn … Yandex Music RPC.exe ENOENT`** или не подключался порт **8765**, значит в системе осталась **старая** установка. Полностью удалите её и поставьте свежий установщик с релизов (версия **1.5.2** и новее):

1. Закройте приложение и Discord (по желанию).
2. **Параметры Windows** → **Приложения** → найдите **Yandex Music RPC** → **Удалить**.
3. При необходимости удалите папку  
   `%LocalAppData%\Programs\yandex-music-discord-rpc\`  
   (Win+R → вставьте путь → Enter).
4. Установите новый `.exe` и запустите программу. Вверху окна должна быть видна актуальная **версия** из сборки.

## Что должно быть запущено

- **Discord** (программа для Windows)
- **Яндекс.Музыка** — официальный клиент для Windows

## Настройки

После нажатия «Настройки» доступны разделы: **Статус**, **Discord**, **Внешний вид**, **Логи**. Всё на русском.

## Обложка в Discord

С мостом в клиенте обложка берётся напрямую из плеера. Без моста — через поиск по названию (иногда может ошибиться).

## Мост в клиент (точность)

Мост читает состояние плеера внутри Яндекс.Музыки и шлёт его на `http://127.0.0.1:8765/track`. Это не полный мод: только RPC, без обхода Плюса и скачивания.

Из исходников:

```bash
pnpm run bridge:install
pnpm run bridge:status
pnpm run bridge:uninstall
```
