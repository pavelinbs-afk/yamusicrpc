# Яндекс.Музыка → Discord

Обычное приложение для Windows: Без командной строки и без лишних окон.

[Скачать](https://github.com/pavelinbs-afk/yamusicrpc/releases/tag/v2.3.0)

Типы установщиков после **[локальной сборки:](https://github.com/pavelinbs-afk/yamusicrpc/releases/tag/v2.3.0)**

- `.exe` (NSIS) — обычный мастер установки, ярлык в меню «Пуск».
- `.msi` — по желанию, тот же продукт в формате Windows Installer (удобно для корпоративных сценариев).
- `portable.exe` — один файл, без установки в систему.

Внутри уже упакованы программа, движок Electron и нужные библиотеки.

## Два приложения — зачем

**Яндекс.Музыка** — обычный официальный плеер: треки, аккаунт, кнопка «play».

**Yandex Music RPC** — не «вторая Музыка», а программа рядом с ней. Она:

- показывает статус в Discord более точно;
- при старте открывает официальную Музыку **с портом отладки** и **считывает** плеер через этот порт (позиция, длительность, обложка, ссылка на трек).

Раньше точность давала **вшивка в** `app.asar` (патч внутри клиента). С Яндекс.Музыкой **5.128+** так нельзя: проверка целостности пакета ломает клиент. Порт CDP — **замена asar**: те же точные данные, но снаружи, без правки файлов Музыки.

## Что сделать

1. Установи программу из собранного `.exe`, `.msi` или portable (файлы появляются в папке `release/` после сборки).
2. Запусти установщик и пройди шаги (для portable — просто запусти файл).
3. Открой **Yandex Music RPC** из меню **«Пуск»** — окно со статусом Discord.
4. Держи открытым **Discord**. При старте RPC сам откроет Музыку с портом (если ещё не запущена). Ярлыки на рабочий стол не создаются.
5. Войди в аккаунт (если нужно) и **включи воспроизведение** — в профиле Discord появится статус «слушает …».
6. Мост ставится **сам** при установке (`.exe` / `.msi`) и при запуске RPC (в т.ч. portable). Если Яндекс.Музыки ещё нет — доустановится при следующем запуске. В **Настройки → Статус** можно **проверить**, **удалить** мост или выключить автоустановку. Без моста статус всё равно работает через системный медиа‑транспорт (менее точно).

В окне программы сверху полоска **RPC**, рядом отображается **версия**, ниже — строка с текущим треком; кнопка **«Настройки»** открывает разделы в том же окне.

## Обновление со старой сборки

Если при запуске была ошибка `spawn … Yandex Music RPC.exe ENOENT` или не подключался порт **8765**, значит в системе осталась **старая** установка. Полностью удалите её и поставьте свежий установщик с релизов (версия **1.5.2** и новее):

1. Закройте приложение и Discord (по желанию).
2. **Параметры Windows** → **Приложения** → найдите **Yandex Music RPC** → **Удалить**.
3. При необходимости удалите папку

   `%LocalAppData%\Programs\yandex-music-discord-rpc\`  
     (Win+R → вставьте путь → Enter).
4. Установите новый `.exe` и запустите программу. Вверху окна должна быть видна актуальная **версия** из сборки.

## Что должно быть запущено

- **Discord** (программа для Windows)
- **Яндекс.Музыка** — официальный клиент для Windows (лучше с портом CDP, см. ниже)
- **Yandex Music RPC** (из «Пуск»)

## Настройки

После нажатия «Настройки» доступны разделы: **Статус**, **Discord**, **Внешний вид**, **Логи**. Всё на русском.

## Обложка в Discord

С мостом обложка берётся из плеера в высоком разрешении (1000×1000). Без моста — поиск Яндекс / Deezer XL / iTunes HD.

## Мост (порт вместо asar)

Мост — схема «порт вместо asar»: **Yandex Music RPC** поднимает Музыку с `--remote-debugging-port=9229`, читает плеер и шлёт данные на `http://127.0.0.1:8765/track`. Ярлыки на рабочий стол **не создаются** — только launcher в `%APPDATA%\yandex-music-rpc` и автозапуск плеера из RPC.

Почему не правим `app.asar`: с **5.128+** любая правка → `ERR_FAILED −2` и вечный перезапуск. CDP-порт — **замена** старого `require`/asar-моста.

Обычный запуск Яндекс.Музыки (без порта) тоже можно: статус через системный медиа‑транспорт — грубее.

При старте **Yandex Music RPC** сам открывает Музыку с портом, если она ещё не запущена. Если Музыка уже открыта без порта 9229 — закрой её и снова запусти **Yandex Music RPC**.

Удаление моста в настройках снимает launcher и старые ярлыки со стола (если остались).
